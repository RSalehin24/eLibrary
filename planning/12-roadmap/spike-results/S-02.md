# S-02 result: Angular, Material M3 and SSR

Status: PARTLY DONE (2026-11-20): the SSR, theming and build questions are answered; the items that need unapproved tools or real devices are open (listed below). ADR-0014 stands; nothing found reopens it.

## Pinned versions (D-67)

Angular CLI and `@angular/{core,common,compiler,forms,platform-browser,platform-server,router,ssr}` 22.3.0, `@angular/material` and `@angular/cdk` 22.3.0 (exact), `rxjs` 7.8.2, `typescript` 6.0.3, `tslib` 2.9.1; dev: `@angular/build`, `@angular/compiler-cli`, `vitest` 5.1.1, `jsdom` 31.0.1, `prettier` 3.10.1, `@types/node`. Node 24 in the image (Angular 22 needs Node 22.22.3+, 24.15+ or 26+). npm 12 blocks dependency install scripts by default; none is approved (`msgpackr-extract` is skipped).

**`express` is not used.** The CLI scaffold adds `express` and `@types/express`; they are removed (they were not in D-67). `web/src/server.ts` uses `node:http` with `@angular/ssr/node`: a small static-file handler confined to the browser build (traversal attempts give 404), `/internal/health`, and SIGTERM handling (the S-06 lesson).

## What was built

`web/`: M3 theme with `mat.theme` (azure palette, Noto Sans Bengali, `color-scheme: light dark`), toolbar, and a server-rendered book detail page (`/books/:slug`: resolver, `Title` and `Meta`, card and chips), one component test (vitest and jsdom, passes), strict tsconfig (`strict`, `noUncheckedIndexedAccess`, `exactOptionalPropertyTypes`, `strictTemplates`), a `web` image (330 MB) and a Compose service behind Caddy.

## Findings

1. **Allowed hosts (SSRF protection).** The server refuses any Host header not allow-listed (`NG_ALLOWED_HOSTS`, or `security.allowedHosts` in `angular.json`): a per-environment deployment setting.
2. **Proxy headers.** `X-Forwarded-*` is ignored unless trusted: `trustProxyHeaders` is set to `x-forwarded-host` and `x-forwarded-proto` only, because the sole caller is Caddy.
3. **SSR data calls.** A relative `/api/...` URL resolves to the public host, which the container cannot reach. An interceptor prefixes `/api/` with `ELIBRARY_API_ORIGIN` on the server only (INV-WEB-024: browser and server share one client).
4. **Material 22 has no navigation rail, bottom navigation bar, side sheet or search component** (its component folders are `sidenav`, `bottom-sheet`, `toolbar`, `tabs`, `menu` and others). These must be built from CDK and tokens: the gap is composable but not yet proven.
5. `ulimit -v` cannot cap Node or esbuild (V8 and Go reserve large virtual ranges); heavy web jobs use `systemd-run --user --scope -p MemoryMax=20G` instead (a deviation from the CLAUDE.md wording, same intent).
