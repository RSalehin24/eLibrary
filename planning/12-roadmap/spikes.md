# Spikes (time-boxed risk reducers)

Status: DRAFT

Re-baselined 2026-11-19 for the six-service design. Each spike answers one question, produces a short written result and an ADR update. Throwaway code stays out of the main workspace. **No crate or package is approved before the P1 batch (D-17, D-20)**, so P0 spikes use only the standard library, SQL, shell and the tools the owner approves for installation (Docker, Node, Java); a spike that needs a crate runs after the batch. Kept from v1: S-01, S-02, S-03, S-04, S-05, S-07 (changed); S-06 (legacy password hashes) is dropped with the migration (D-32) and its number is reused.
