# Requirements — Content (CON)

Status: DRAFT · Services: [catalog](../05-services/catalog/README.md) (versions, assets, downloads), [reader](../05-services/reader/README.md) (reading copies) and [ingestion](../05-services/ingestion/README.md) (build). D-27/D-28: the former content service is dissolved; ids keep the CON prefix

- **REQ-CON-001** · MUST · inv: INV-CON-001 · verify: db, model, prop · Book versions and their assets are immutable and content-addressed (sha256). Publishing a version is an atomic switch of the published version; readers see either the old or the new version, never a mix. A reading copy is keyed by `(book_id, version)`.
- **REQ-CON-002** · MUST · inv: INV-CON-002 · verify: prop, gold · EPUB and Preview are derived deterministically from the curated document by ingestion, and the reading copy deterministically from the EPUB by reader: same input and builder version produce byte-identical output.
- **REQ-CON-003** · MUST · inv: INV-CON-003 · verify: type, prop · The Preview is built by ingestion at build time from an allow-list (metadata, summary, TOC, first N characters of the first chapter). Public catalog endpoints can only serve the Preview, never the full document.
- **REQ-CON-004** · MUST · inv: INV-CON-004 · verify: type, e2e · The whole rendered book is served only against a valid reading ticket for that user, book and version; EPUB downloads only after a `download` scope check by catalog. Caddy never serves files directly.
- **REQ-CON-005** · SHOULD · inv: INV-CON-005 · verify: prop · Byte-range requests return correct partial content for downloads and reading-copy resources.
- **REQ-CON-006** · MUST · inv: INV-CON-006 · verify: db, drill · Files of the previous published version are kept until the next version is approved (D-27 defaults); annotations on the old version are re-anchored by reader and never deleted (see REQ-LIB-002).
- **REQ-CON-007** · MUST · inv: INV-CON-007 · verify: prop, gold · Every EPUB passes epubcheck and the structure audit; navigation and in-book TOC are generated from the same tree so they cannot differ; page order follows the [fixed order](../05-services/ingestion/builder/README.md).
- **REQ-CON-008** · MUST · inv: INV-CON-008 · verify: gold, review · Covers use the source image when present; otherwise a generated cover shows title and author with correct Bengali shaping, portrait ratio, readable contrast.
- **REQ-CON-009** · MUST · inv: INV-CON-009 · verify: type, fuzz · All HTML passes through a `SafeHtml` sanitizer type; scripts, inline handlers, external loads and unknown URL schemes cannot appear in stored output.
- **REQ-CON-010** · MUST · inv: INV-CAT-001, INV-ING-003 · verify: model, e2e · Publish gate: ingestion submits a build candidate to catalog, which makes it `in_review`; only approval (scope `manage_catalog`) makes it `published`. A failed or unapproved build is never visible to readers.
- **REQ-CON-011** · MUST · inv: INV-PLT-009, INV-PLT-003 · verify: model, prop · On `book.published` reader fetches the EPUB from catalog, parses and sanitizes it once and stores the reading copy; the step is idempotent per `(book_id, version)`, and events are consumed from catalog's outbox with a stored cursor, tolerating duplicates and restarts.
