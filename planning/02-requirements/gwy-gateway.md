# Requirements - Gateway (GWY)

Status: DRAFT · Service: [gateway](../05-services/gateway/README.md)

Line format: `REQ-ID · priority · inv: <invariants> · verify: <methods> · statement`

- **REQ-GWY-001** · MUST · inv: INV-GWY-001 · verify: e2e, review · Caddy only terminates HTTPS and renews certificates and forwards `/` to `web` and everything else to `gateway`. Only `/api/<service>/*` routes are exposed to the public; `/internal/*`, service ports, databases and file volumes are never routed (answers X1-011).
- **REQ-GWY-002** · MUST · inv: INV-GWY-002 · verify: e2e, unit · For every `/api/*` request except the public routes the gateway calls identity `/internal/authorize` and forwards the request only on Allow. Missing or invalid session returns 401; a denied request returns 403; an unreachable or timed-out identity returns 503. The gateway never allows on error (fail closed) (answers X1-002).
- **REQ-GWY-003** · MUST · inv: INV-GWY-003 · verify: type, e2e · The public routes are a closed allow-list in code: identity sign-in, invite acceptance, password reset request and confirm, catalog metadata browse, search and detail (covers and summaries; no preview text, D-34). A route not on the list requires a session; adding to the list requires a plan change (answers X1-006).
- **REQ-GWY-004** · MUST · inv: INV-GWY-004 · verify: e2e, fuzz · The gateway removes every client-supplied identity header (user id, scopes, request id, service token) and sets them only from the identity response; downstream services trust these headers only when they arrive with a valid internal service token. Reading tickets, cookies and authorization headers are never written to logs.
- **REQ-GWY-005** · MUST · inv: INV-GWY-005 · verify: e2e · Cookie-authenticated mutations require a CSRF token bound to the session and a matching `Origin`; the token is delivered with the session response so no extra request precedes a mutation; cookies are HttpOnly, Secure and SameSite; cross-origin requests are rejected (answers X1-078).
- **REQ-GWY-006** · MUST · inv: INV-GWY-006 · verify: e2e, unit · Every request has a request id (generated when absent, validated when supplied), propagated to every service, returned in the response and present in every log line.
- **REQ-GWY-007** · MUST · inv: INV-GWY-007 · verify: prop, e2e · Rate limits apply per address and per authenticated subject, stricter for anonymous and authentication routes; counters are held in bounded in-memory tables (no cache service); excess returns 429 with `Retry-After`.
- **REQ-GWY-008** · MUST · inv: INV-GWY-008 · verify: review, type · The gateway contains no business logic: it holds no database, no domain types and no scope decisions of its own; routing, session check, public allow-list, rate limits, CSRF, request ids, headers and error mapping are its only duties.
- **REQ-GWY-009** · MUST · inv: INV-GWY-009 · verify: e2e · Security headers (CSP, HSTS, frame, referrer, content-type options) are set on every response that leaves the stack: by the gateway for API responses and by the edge for static assets.
- **REQ-GWY-010** · MUST · inv: INV-GWY-010 · verify: prop, e2e · The gateway enforces bounds: maximum header and body size per route class, upstream and identity timeouts, a concurrency limit per upstream, and a limit on open streams; large responses are streamed without buffering the whole body (answers X1-076).
- **REQ-GWY-011** · MUST · inv: INV-GWY-011 · verify: e2e, review · Files (EPUBs, covers, reading copies) are never served by Caddy or the gateway from disk; the gateway only proxies a service's own authorized stream; there is no `/media/` path (answers X1-011).
- **REQ-GWY-012** · MUST · inv: INV-GWY-012 · verify: e2e · Errors from the gateway and upstream failures are mapped to the platform typed error envelope (stable code, request id, no internals): upstream timeout 504, upstream failure 502, overload 503.
- **REQ-GWY-013** · SHOULD · inv: INV-GWY-013 · verify: e2e · Server-Sent Events from the ingestion console pass through the gateway as streams: authorized when opened, closed on idle timeout and on session revocation, without buffering.
- **REQ-GWY-014** · MUST · inv: INV-GWY-014 · verify: e2e · The gateway exposes liveness and readiness endpoints on an internal port only; readiness reports whether identity is reachable.
