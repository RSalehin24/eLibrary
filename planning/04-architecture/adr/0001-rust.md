# ADR-0001 — Rust for backend and shared code

Status: ACCEPTED

## Context
The owner wants an implementation where whole classes of runtime errors cannot occur. The legacy Django system's defects were dominated by null/typing mistakes, illegal states and untyped contracts.

## Decision
All backend services, domain logic and shared contract crates are Rust (stable, pinned). Frontend technology is decided separately (ADR-0014).

## Consequences
+ Ownership, sum types, exhaustive matching, `Result` and newtypes remove error classes 1–7, 12, 14 in the [catalog](../../03-correctness/error-class-elimination.md).
+ Single language for contract, domain and services.
− Slower initial delivery; fewer ready-made admin/CRUD tools than Django; Bengali text libraries are thinner (mitigated by `domain-text` and spikes S-01/S-03).
− One developer must hold Rust + SQL + TLA+ skills; the plan keeps each tool's footprint small.
